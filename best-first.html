      평가 함수f(n) = h(n)f(n) = g(n) + h(n)
      보는 정보목표까지 남은 예상 거리만출발점에서 온 실제 거리 + 남은 예상 거리
      비유목표 방향만 가리키는 탐지기를 든 로봇탐지기에 주행 기록계까지 함께 보는 로봇
      장점목표 쪽으로 곧장 달려가 확장하는 노드 수가 적은 편h가 실제 거리보다 크지 않으면 최단 경로를 보장
      단점최단 경로를 보장하지 않음 (함정에 빠질 수 있음)더 많은 노드를 확장해 시간과 메모리가 더 들 수 있음
      휴리스틱 h(n)여기서는 기본값으로 목표까지의 직선거리를 씁니다. 🔢 값 편집으로 직접 바꿀 수 있습니다.
      사용 방법
      1. ✏️ 그리기: 빈 곳을 탭하면 노드가 생기고, 노드 → 다른 노드 순서로 탭하면 길(간선)이 연결됩니다. 노드를 끌면 위치가 바뀝니다.
      2. 간선 위 숫자는 실제 거리(비용), 노드 위 h는 목표까지의 직선거리입니다. 노드를 옮기면 자동으로 다시 계산됩니다.
      3. 🔢 값 편집: 간선을 탭하면 거리, 노드를 탭하면 h를 직접 입력할 수 있습니다(공사 중인 길, 언덕길 등). 보라색은 직접 입력한 값입니다.
      4. 🚩 출발 / 🏁 도착 버튼을 누른 뒤 노드를 탭해 출발점과 도착점을 정합니다.
      5. ▶ 재생으로 두 탐색이 열린 목록에서 노드를 하나씩 꺼내는 과정을 비교하세요. 아래 기록은 활동지에 옮겨 적기 좋습니다.
